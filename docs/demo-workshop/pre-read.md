# Before the workshop

## 1. Prerequisite: Connect your agent and obtain an API key

Follow [Connect Your Agent](https://dev.nominal.io/quickstart/mcp/#connect) to connect your agent to the Nominal [MCP](https://dev.nominal.io/platform/reference/glossary/#model-context-protocol-mcp). Your agent uploads the sample data with the Python client, so also [install it](https://dev.nominal.io/python/guides/install/) and [set up a profile](https://dev.nominal.io/quickstart/api-keys-setup/). The instructions provided assume a workspace called `sandbox` and a [profile](https://dev.nominal.io/platform/reference/glossary/#profile) called `sandbox`, but any workspace may be used. Sandbox is recommended to avoid other users accidentally consuming demo data.
